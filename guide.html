USER DOCUMENTATION

Write scripts the worker can render.

One rule: your script creates geometry only. Scene cleanup, studio lighting, camera framing and file export happen automatically around it.

Include

  • import bpy plus math / mathutils if needed
  • At least one MESH — primitives, modifiers, from_pydata
  • Descriptive object names, e.g. cube.name = "Bolt"
  • shade_smooth() on finished meshes
  • Principled BSDF materials for colour and roughness
  • print() lines — they land in the worker log

Leave out

  • Scene clearing — the worker wipes the scene first
  • Collection setup — handled before your code runs
  • export_scene.* — export is automatic per format
  • Render engine / sample settings — set by the quality preset
  • File, network or subprocess access — blocked, job fails
  • sys.exit() and infinite loops — 5 min timeout, then failed

When a job fails

Match the worker message to the cause.

No mesh objects created

  • Script ran but produced no MESH — check primitive calls and typos

USER_SCRIPT_ERROR

  • Python exception in your code — the traceback points at your line

EXPORT_ERROR

  • Geometry exists but export crashed — try draft quality to isolate

Stuck on processing

  • Usually a long loop or heavy subdivisions — simplify and resubmit
